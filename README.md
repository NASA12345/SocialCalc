# SocialCalc

A collaborative spreadsheet web app.

## What it does

- Create and edit spreadsheets in the browser
- Real-time collaboration across multiple users
- Supports formulas like SUM, AVERAGE, etc.
- Infinite rows and columns with smooth scrolling
- Copy/paste support from Excel or CSV files

## How to run

```bash
git clone https://github.com/NASA12345/SocialCalc.git
cd SocialCalc
npm install
node index.js
```

Open `http://localhost:3000` in your browser and you're good to go.

## Built with

- Javascript, React.js, Tailwind CSS, Firebase
